# Constance Mod Manager

A Mods Manager to install and manage mods for the game **Constance**.

---

## Features

- Drag & drop `.dll` mod installation
- Enable / disable mods with a toggle
- Automatic BepInEx installation
- Multi-language support (EN, FR, ES, ZH, HI)
- Auto-detects the Constance game folder via Steam

---

## Requirements

- Windows
- [Constance](https://store.steampowered.com/app/2313700/Constance/) on Steam

BepInEx is bundled — no manual installation needed.

---

## Installation

1. Download the latest `ConstanceModManager.zip` from the [Releases](../../releases)
2. Place it anywhere on your PC
3. Launch it — it will auto-detect your Constance install
